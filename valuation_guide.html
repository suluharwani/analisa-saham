Panduan Metode Valuasi Saham — Keputusan Investasi

Dokumen ini menjelaskan 16 metode penghitungan harga wajar saham yang digunakan dalam sistem Analisa Valuasi Emiten BEI. Setiap metode dilengkapi dengan formula, contoh perhitungan, dan panduan pengambilan keputusan investasi.

Catatan Penting: Tidak ada satu metode pun yang sempurna. Gunakan kombinasi beberapa metode (consensus) untuk keputusan yang lebih robust. Data valuasi bukan rekomendasi jual/beli — keputusan investasi sepenuhnya tanggung jawab pengguna.

1. Graham Number

Benjamin Graham's Formula

Graham Number = √(22.5 × EPS × BVPS)

Penjelasan: Formula klasik Benjamin Graham untuk menentukan harga wajar maksimum yang boleh dibayar untuk sebuah saham. Angka 22.5 berasal dari PE maksimum 15x dan PBV maksimum 1.5x (15 × 1.5 = 22.5).

Cara Penggunaan:

  • Jika Harga Pasar < Graham Number → saham undervalued, potensi BELI
  • Jika Harga Pasar > Graham Number → saham overvalued, HINDARI/JUAL
  • Semakin besar selisih (Graham - Harga), semakin besar margin of safety
BELI jika Harga < Graham Number
JUAL/AVOID jika Harga > Graham Number
Contoh BBCA: EPS=482.77, BVPS=2309.19 → Graham = √(22.5 × 482.77 × 2309.19) = Rp 5,008. Harga pasar Rp 5,025 → sedikit di atas Graham (margin tipis, HOLD/AVOID).

Keterbatasan: Hanya cocok untuk perusahaan dengan earning stabil. Tidak cocok untuk bank/financial (karena leverage tinggi) dan perusahaan growth.

2. PE-Based Fair Value (15x & 12x)

Price-to-Earnings Based

Fair Value = EPS × 15 (atau EPS × 12)

Penjelasan: Harga wajar berdasarkan rasio PE (Price-to-Earnings). PE 15x adalah standar Graham untuk perusahaan dengan pertumbuhan normal. PE 12x adalah rata-rata pasar IDX.

Cara Penggunaan:

  • PE < 15 → saham murah relatif earning → BELI
  • PE 15-25 → fair value → HOLD
  • PE > 25 → mahal → AVOID/JUAL
  • Bandingkan PE perusahaan dengan PE sektor (relative valuation)
BELI jika PE < 15 (atau < sektor)
JUAL jika PE > 25 (atau > sektor secara signifikan)
Contoh BBCA: EPS=482.77, PE=10.4x → Fair Value 15x = Rp 7,242. Harga Rp 5,025 → undervalued 44%. BELI.

Keterbatasan: Tidak mempertimbangkan growth rate. Perusahaan dengan growth tinggi bisa justify PE tinggi.

3. PBV-Based Fair Value (1.0x & 1.5x)

Price-to-Book Value Based

Fair Value = BVPS × 1.0 (atau BVPS × 1.5)

Penjelasan: Harga wajar berdasarkan PBV (Price-to-Book Value). PBV 1.0x berarti harga = nilai buku. PBV 1.5x adalah premium wajar untuk perusahaan dengan ROE > cost of capital.

Cara Penggunaan:

  • PBV < 1.0 → saham di bawah nilai buku → BELI (margin of safety tinggi)
  • PBV 1.0-1.5 → fair value → HOLD
  • PBV > 2.0 → premium, perlu justifikasi growth/ROE tinggi
  • PBV > 3.0 → mahal, AVOID (kecuali growth sangat tinggi)
BELI jika PBV < 1.0
HOLD jika PBV 1.0-1.5
AVOID jika PBV > 3.0 tanpa justifikasi growth
Contoh BBCA: BVPS=2,309, PBV=2.18x → Fair Value 1.0x = Rp 2,309 (di bawah harga). PBV 2.18x premium tapi justified oleh ROE 20.9%. HOLD/BUY dengan catatan.

4. Asset-Based (NAV per Share)

Net Asset Value

NAV/share = Ekuitas / Jumlah Saham

Penjelasan: Nilai aset bersih per saham. Sama dengan BVPS (Book Value Per Share). Menunjukkan nilai perusahaan jika dilikuidasi.

Cara Penggunaan:

  • NAV/share tinggi relatif harga → saham murah (asets backing)
  • Cocok untuk perusahaan asset-heavy (properti, manufaktur, tambang)
  • Kurang relevan untuk perusahaan asset-light (tech, jasa)
BELI jika Harga < NAV (margin of safety)
Contoh BBCA: NAV = Rp 2,309 (sama dengan BVPS). Harga Rp 5,025 → premium 2.18x, tapi justified oleh earning power.

5. Liquidation Value

Nilai Likuidasi

Liquidation Value = (Total Aset - Total Liabilitas) / Saham

Penjelasan: Nilai yang diterima pemegang saham jika perusahaan dilikuidasi. Konservatif — hanya memperhitungkan aset bersih.

Cara Penggunaan:

  • Liquidation Value > Harga Pasar → "net-net" (Graham's net-net) → STRONG BUY
  • Liquidation Value < Harga → normal, perusahaan valued as going concern
  • Cocok untuk screening saham murah dengan aset kuat
STRONG BUY jika Harga < Liquidation Value (net-net)
Contoh BBCA: Liquidation = (1,641,511 - 1,357,850) / 122.84 miliar = Rp 2,309. Harga Rp 5,025 → premium (normal untuk bank).

6. Earnings Power Value (EPV)

Nilai Kekuatan Laba

EPV = EPS / r (r = required return, default 10%)

Penjelasan: Nilai perusahaan berdasarkan kemampuan menghasilkan laba saat ini, tanpa asumsi growth. r = required return (cost of capital).

Cara Penggunaan:

  • EPV > Harga Pasar → saham murah (laba cukup untuk justify harga)
  • EPV < Harga Pasar → saham mahal (perlu growth untuk justify)
  • Cocok untuk perusahaan dengan laba stabil dan predictable
BELI jika EPV > Harga (margin of safety dari earning power)
AVOID jika EPV << Harga (terlalu bergantung pada growth)
Contoh BBCA: EPV = 482.77 / 0.10 = Rp 4,828. Harga Rp 5,025 → sedikit di bawah EPV. HOLD/AVOID (margin tipis).

7. Dividend Discount Model (Gordon Growth)

Model Diskonto Dividen

DDM = D1 / (r - g) dimana D1 = EPS × payout × (1+g)

Penjelasan: Nilai saham berdasarkan present value dari semua dividen masa depan. Cocok untuk perusahaan yang rutin membayar dividen.

Parameter: r = required return (10%), g = growth rate dividen (3%), payout = 30%

Cara Penggunaan:

  • DDM > Harga Pasar → saham murah (dividen cukup tinggi)
  • DDM < Harga Pasar → saham mahal (dividen yield rendah)
  • Cocok untuk perusahaan mature dengan dividend yield tinggi
  • Tidak cocok untuk growth stocks yang tidak bayar dividen
BELI jika DDM > Harga (dividend yield menarik)
Contoh BBCA: D1 = 482.77 × 0.30 × 1.03 = Rp 149.2. DDM = 149.2 / (0.10-0.03) = Rp 2,131. Harga Rp 5,025 → DDM < Harga (dividend yield rendah, growth play).

8. Residual Income Model

Model Pendapatan Residual

RI = BVPS + (ROE - r) × BVPS / (r - g)

Penjelasan: Nilai saham = nilai buku + present value dari residual income (laba di atas cost of capital). Mempertimbangkan ROE vs required return.

Cara Penggunaan:

  • ROE > r → perusahaan menciptakan value → RI > BVPS → BELI
  • ROE = r → value neutral → RI = BVPS → HOLD
  • ROE < r → perusahaan menghancurkan value → RI < BVPS → AVOID
BELI jika ROE > 10% (cost of capital) dan RI > Harga
AVOID jika ROE < 10% (value destroyer)
Contoh BBCA: ROE=20.9%, RI = 2309 + (0.209-0.10)×2309/(0.10-0.03) = Rp 5,945. Harga Rp 5,025 → RI > Harga → BELI (value creator).

9. Graham's Revised Formula

Formula Graham Revisi

Fair Value = EPS × (8.5 + 2g) dimana g = growth rate (%)

Penjelasan: Versi revisi formula Graham yang mempertimbangkan growth rate. 8.5 adalah PE untuk perusahaan tanpa growth, 2g adalah premium untuk growth.

Cara Penggunaan:

  • Fair Value > Harga → saham murah (growth tidak terharga)
  • Fair Value < Harga → saham mahal (growth sudah terharga penuh)
  • Cocok untuk perusahaan dengan growth moderate (5-15%)
BELI jika Fair Value > Harga dengan margin > 20%
Contoh BBCA: g=5%, FV = 482.77 × (8.5 + 10) = Rp 8,931. Harga Rp 5,025 → undervalued 78%. BELI.

Keterbatasan: Growth rate diasumsikan (5% default). Perlu adjust sesuai prospek perusahaan.

10. PEG-Based Fair Value

Price/Earnings-to-Growth

Fair Value = EPS × Growth Rate (%) (PEG = 1)

Penjelasan: Fair value dengan asumsi PEG ratio = 1 (fair valuation). PEG = PE / Growth Rate. PEG < 1 = undervalued, PEG > 1 = overvalued.

Cara Penggunaan:

  • PEG < 1.0 → saham undervalued relatif growth → BELI
  • PEG 1.0-2.0 → fair value → HOLD
  • PEG > 2.0 → overvalued → AVOID
BELI jika PEG < 1.0
HOLD jika PEG 1.0-2.0
AVOID jika PEG > 2.0
Contoh BBCA: PE=10.4, Growth=5% → PEG = 10.4/5 = 2.08 → Fair Value = 482.77 × 5 = Rp 2,414. Harga Rp 5,025 → PEG > 1, mahal. AVOID/HOLD.

11. DCF (Simplified Perpetuity)

Discounted Cash Flow

DCF = EPS × (1+g) / (r - g_perpetuity)

Penjelasan: Nilai present value dari semua cash flow masa depan, diasumsikan perpetuity (tumbuh selamanya). g = growth rate, r = discount rate.

Parameter: g=5%, r=10%, g_perpetuity=3%

Cara Penggunaan:

  • DCF > Harga Pasar → saham undervalued → BELI
  • DCF < Harga Pasar → saham overvalued → AVOID
  • Sangat sensitif terhadap asumsi growth dan discount rate
BELI jika DCF > Harga dengan margin > 30%
Contoh BBCA: DCF = 482.77 × 1.05 / (0.10-0.03) = Rp 7,242. Harga Rp 5,025 → undervalued 44%. BELI.

Keterbatasan: Asumsi perpetuity tidak realistis untuk semua perusahaan. Perlu adjust growth rate.

12. Earnings Yield

Hasil Laba

Earnings Yield = (EPS / Harga) × 100%

Penjelasan: Inverse dari PE ratio. Menunjukkan berapa persen return yang didapat dari laba per saham. Semakin tinggi semakin murah.

Cara Penggunaan:

  • EY > 10% (PE < 10) → saham sangat murah → STRONG BUY
  • EY 6.7-10% (PE 10-15) → murah → BUY
  • EY 4-6.7% (PE 15-25) → fair → HOLD
  • EY < 4% (PE > 25) → mahal → AVOID
  • Bandingkan dengan yield obligasi (risk-free rate ~6.5%)
BELI jika EY > risk-free rate (6.5%) dengan margin
Contoh BBCA: EY = 482.77/5025 × 100 = 9.61%. PE=10.4x. EY > 6.5% → murah. BELI.

13. Magic Formula (Greenblatt)

Joel Greenblatt's Magic Formula

Magic Score = Earnings Yield (%) + Return on Capital (%)

Penjelasan: Strategi Joel Greenblatt: beli perusahaan dengan earning yield tinggi DAN return on capital tinggi. Kombinasi "murah" dan "bagus".

Cara Penggunaan:

  • Score tinggi → perusahaan murah (EY tinggi) DAN efisien (ROC tinggi) → STRONG BUY
  • Score rendah → mahal atau tidak efisien → AVOID
  • Ranking: sort by score descending, beli top 20-30
BELI saham dengan Magic Score tertinggi (top 20-30)
Contoh BBCA: EY=9.61%, ROC=20.93% → Score=30.54. Score tinggi → STRONG BUY (murah + efisien).

Keterbatasan: ROC sederhana (NI/Equity) tidak memperhitungkan struktur modal. Perlu refinement untuk perusahaan dengan leverage tinggi.

14. NCAV (Net Current Asset Value)

Nilai Aset Lancar Bersih

NCAV = (0.8 × Total Aset - Total Liabilitas) / Saham

Penjelasan: Nilai aset lancar bersih per saham dengan margin of safety 20% (hanya 80% aset dihitung). Konservatif — Graham's net-net screening.

Cara Penggunaan:

  • NCAV > Harga Pasar → "net-net" → STRONG BUY (margin of safety sangat tinggi)
  • NCAV < 0 → perusahaan tidak punya aset lancar cukup → AVOID
  • Sangat konservatif, jarang ditemukan di pasar modern
  • Cocok untuk deep value investing
STRONG BUY jika Harga < NCAV (net-net)
AVOID jika NCAV < 0 (liabilitas > aset)
Contoh BBCA: NCAV = (0.8 × 1,641,511 - 1,357,850) / 122.84 = (1,313,209 - 1,357,850)/122.84 = -Rp 363. NCAV negatif → AVOID (bank leverage tinggi, NCAV tidak applicable).

Keterbatasan: Tidak cocok untuk financial/bank (leverage tinggi). Cocok untuk manufaktur/retail dengan aset lancar tinggi.

Strategi Kombinasi (Consensus)

Rekomendasi: Jangan gunakan satu metode saja. Gunakan consensus (rata-rata/median) dari minimal 5-7 metode. Keputusan investasi:
  • STRONG BUY: ≥ 70% metode menunjukkan undervalued + soliditas Solid + tidak ada red flag
  • BUY: ≥ 50% metode undervalued + soliditas Moderat/Solid
  • HOLD: Metode campuran (50/50) atau Netral
  • AVOID/SELL: ≥ 70% metode overvalued ATAU soliditas Rawan Gorengan ATAU ekuitas negatif
